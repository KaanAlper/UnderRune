UnderRune

DELTARUNE boss battles in your browser, running the game's own code from your own copy. Every attack is the original, not a remake.

View the source on GitHub

The real fights

All 49 boss encounters from chapters 1 to 5 load and reach combat with their original attacks, music and dialogue. These clips are recorded from the app.

How it works

The game's own code

The open-source Butterscotch GameMaker runner, compiled to WebAssembly, runs the bytecode in your installed data.win. A small patch adds positional audio and compiles the game's shaders for WebGL2.

Straight into the fight

A launcher copy of each chapter changes only the startup step, then starts the chosen encounter through the game's own scr_battle. Each party is taken from the game code: Susie fights Hammer of Justice alone, as in the game.

Your gear, their rules

Before a fight you equip weapons and armor and pack the 12-slot bag. Names, stats and who can wear what come from the game data, and the battle uses exactly that loadout.

Run it yourself

You need your own copy of DELTARUNE installed through Steam. Nothing from the game is in the repository; everything is read from your installation on your computer.

git clone https://github.com/KaanAlper/UnderRune
cd UnderRune
npm install
npm run prepare:game
npm run setup:native
npm run dev

Then open http://127.0.0.1:5173. Requirements, controls and the test suite are in the README.
